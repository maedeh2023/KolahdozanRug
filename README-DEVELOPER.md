# راهنمای توسعه‌دهنده سورس‌کد گالری فرش کلاهدوزان

این بسته حاوی سورس‌کد کامل پروژه فرانت‌اند گالری فرش دستباف کلاهدوزان اصفهان با پشته فناوری زیر است:
- **React 18+** همراه با **TypeScript**
- **Vite** (ابزار ساخت و سرور توسعه پرسرعت)
- **Tailwind CSS v4** (سیستم طراحی لوکس)
- **Lucide Icons**
- فونت‌های اصیل فارسی و خوشنویسی (ایران‌نستعلیق، کتیبه، امیری، گلزار شکسته، عارف رقعه، ریم کوفی، میرزا، لطیف، لاله‌زار، شهرزاد و وزیرمتن)

---

## 🚀 پیش‌نیازها و راه‌اندازی سریع

### ۱. نصب وابستگی‌ها
در خط فرمان (Terminal / PowerShell / CMD) در پوشه پروژه دستور زیر را اجرا کنید:
```bash
npm install
```

### ۲. اجرای محیط توسعه (Live Dev Server)
برای اجرای پروژه همراه با Hot-Reload سریع:
```bash
npm run dev
```
سپس آدرس محلی (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

### ۳. بیلد نسخه نهایی (Production Build)
برای ایجاد خروجی بهینه‌سازی‌شده و مستقل:
```bash
npm run build
```
فایل‌های خروجی در پوشه `dist/` قرار می‌گیرند.

## 📁 ساختار پوشه‌های سورس‌کد

```text
├── src/
│   ├── assets/
│   │   └── fonts/         # فونت‌های محلی TTF و WOFF2
│   ├── components/        # کامپوننت‌های رابط کاربری (Navbar, Footer, Modals)
│   ├── data/              # دیتای فرش‌ها و ۱۰ مطالعه تایپوگرافی
│   ├── pages/             # صفحات اصلی (HomePage, Rug25QPage, Rug07PPage, TypographyShowcasePage)
│   ├── types.ts           # تایپ‌های TypeScript و مسیرها
│   ├── index.css          # شیدرهای نورپردازی، سایه‌ها و استایل‌های Tailwind
│   ├── App.tsx            # روتینگ و معماری برنامه
│   └── main.tsx           # نقطه ورود React
├── public/                # فایل‌های استاتیک، تصاویر باکیفیت فرش، لوگوها و فونت‌ها
├── package.json           # پکیج‌ها و اسکریپت‌ها
└── vite.config.ts         # تنظیمات ساخت نسبی (base: './')
```
